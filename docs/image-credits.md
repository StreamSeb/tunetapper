## Regenerating an OG card

The original 11 cards were composed by hand and no generator survived, so
`scripts/og-card.mjs` reconstructs that layout from measurements taken off
`public/og/rhythm-game.png`. With the dev server running:

```bash
npm install --no-save playwright-core
node scripts/og-card.mjs \
  --slug studio-builder \
  --title "Studio Setup Builder" \
  --subtitle "Turn a budget into a complete studio setup." \
  --path /tools/studio-builder
```

It screenshots the live page (dark theme, consent banner suppressed) and
composes it into the branded 1200x630 frame. Long titles wrap and push the
subtitle down rather than colliding with it.

## Notes

**Unsplash License** permits commercial use, including on a site carrying ads
and affiliate links, with no attribution required. It forbids selling
unmodified copies and building a competing stock-photo service — neither
applies here.

**Watch for Unsplash+.** Photos served from `plus.unsplash.com` (URLs containing
`premium_photo-`) are a paid tier and are *not* covered by the free licence,
even though they appear in ordinary search results. Check the CDN hostname
before downloading; `images.unsplash.com` is the free one.

**Not covered here:** merchant product shots for the studio builder. The
`imageUrl` fields in `src/data/gear.json` point at Thomann's CDN and we have no
licence to serve them, so rendering is disabled behind `SHOW_PRODUCT_IMAGES` in
`src/components/tools/studio-builder-tool.tsx`. Licensed replacements come from
the Awin datafeed.
